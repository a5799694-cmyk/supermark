# 梦里修仙 · 三门派版 v0.2

原创社畜修仙、竖屏手动回合制卡牌浏览器原型。已有21种卡牌、三门派、奖励保底、动态牌面、存档与旧版本兼容。尚未接入抖音平台；美术仍为CSS占位。

## Windows启动

解压整个包，进入能看到index.html、src、start_game.py的文件夹。双击「启动游戏.bat」，需要Python 3。程序自动选择空闲端口并打开浏览器，保持命令窗口开启，Ctrl+C停止。

或在文件夹地址栏输入cmd，再运行：

```powershell
py start_game.py
```

仍可使用`python -m http.server 8013`并打开http://localhost:8013；若端口有旧服务，先关闭旧服务。更新后Ctrl+F5。新版页脚为「三门派版 v0.2 · 20261013」。

## 三门派

- 斩仙堂：加班免谈，老细照斩。第3张手动攻击追加3伤害，减费启动，连击收尾。
- 惊雷府：有锅我扛，有雷你尝。首次受生命伤害获得1怒气，怒气可换灵力或爆发。
- 百身门：分身上岗，本体躺躺。战斗开局1分身，围殴、增幅、消耗分身回灵。

开局选门派并确认；点牌查看完整效果，单体攻击点敌人，群攻和技能点确认打出。每回合基础灵力3，回灵可超过3，下回合重置。第一轮奖励保证核心候选，第二轮保证大招候选；只能选一张，也可跳过。

扣血大招明确显示支付6生命：无视护盾，生命须大于6，且至少1分身。所有费用、伤害和护盾预览与规则共用公式；显示伤害为牌面伤害，实际生命损失仍受敌人护盾影响。

## 旧进度

沿用浏览器localStorage键dream-cultivation-v1。v1合法存档迁移为legacy，继续原牌组与原奖励，不追溯发放新门派被动。打完后点「唔服，再嚟」进入门派选择。使用新端口是新的浏览器存档空间，也可直接选新门派。损坏存档需主动确认清除；不会自动覆盖。
