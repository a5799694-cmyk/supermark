# 梦里修仙 · 三门派随机奇遇版 v0.3

原创社畜修仙、竖屏手动回合制卡牌浏览器原型。已有21种卡牌、三门派、奖励保底、动态牌面、存档与旧版本兼容。尚未接入抖音平台；美术仍为CSS占位。

## Windows启动

解压整个包，进入能看到index.html、src、start_game.py的文件夹。双击「启动游戏.bat」，需要Python 3。程序自动选择空闲端口并打开浏览器，保持命令窗口开启，Ctrl+C停止。

或在文件夹地址栏输入cmd，再运行：

```powershell
py start_game.py
```

仍可使用`python -m http.server 8013`并打开http://localhost:8013；若端口有旧服务，先关闭旧服务。更新后Ctrl+F5。新版页脚为「三门派版 v0.3 · 随机奇遇 · 20261013」。

## 三门派

- 斩仙堂：加班免谈，老细照斩。第3张手动攻击追加3伤害，减费启动，连击收尾。
- 惊雷府：有锅我扛，有雷你尝。首次受生命伤害获得1怒气，怒气可换灵力或爆发。
- 百身门：分身上岗，本体躺躺。战斗开局1分身，围殴、增幅、消耗分身回灵。

开局选门派并确认；点牌查看完整效果，单体攻击点敌人，群攻和技能点确认打出。每回合基础灵力3，回灵可超过3，下回合重置。第一轮奖励保证核心候选，第二轮保证大招候选；只能选一张，也可跳过。

扣血大招明确显示支付6生命：无视护盾，生命须大于6，且至少1分身。所有费用、伤害和护盾预览与规则共用公式；显示伤害为牌面伤害，实际生命损失仍受敌人护盾影响。

## v0.3 随机奇遇

新开局在两次普通战斗领奖后各随机出现0–2个事件，每局1–3个且类型不重复。猫摊可换牌，补班可恢复4生命或支付4生命拿牌，打坐可恢复8生命或强化，野鸡秘籍先展示一张牌再决定是否支付4生命获得；均可离开。生命支付后至少剩1点，无货币、无真实广告。

开局保存顺序，事件候选和猫摊选牌自动保存，取消/读档不重抽。旧v2局继续固定流程，结局重开才进入随机奇遇。当前仍为文字/CSS占位，肥猫正式美术尚未接入。详细规则见docs/2026-10-13-random-events.md。真实浏览器布局和真人体验待验证。

## Windows启动修复（2026-10-13）

启动游戏.bat采用ASCII文字和Windows CRLF换行，显式用py -3执行带引号的完整脚本路径；没有py时回退python。修复启动时命令被截断并误入Python交互界面的问题。已经检查文件字节并验证本地HTTP服务及游戏模块返回正常；本环境不能执行Windows cmd，因此Windows端仍需复试。

手动备用方式：在游戏文件夹地址栏输入cmd，回车后运行py -3 start_game.py。若看到>>>，先输入exit()退出Python交互界面。
