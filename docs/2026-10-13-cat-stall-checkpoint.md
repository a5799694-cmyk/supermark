# 梦里修仙：猫摊主阶段确认与下一步

日期：2026-10-13
状态：本轮形象方向暂定；玩法建议待实现与试玩验证。

## 本轮已确认方向

- 延续「白天上班，晚上修仙」的主题，荒诞与吐槽服务于同一个世界观。
- 以用户家的宠物猫作为摊主形象依据，替代此前狐妖方案。
- 体型肥胖，保留参考猫的辨识特征；表情是重点，要有欠欠的、呆贱的鬼畜感，避免变成普通可爱猫。
- 用户形容的「有点小八嘎」用于表达神态气质，不据此添加未经确认的服饰、国籍标志或设定。
- 整体贴合《月圆之夜》式卡牌氛围，采用原创角色与素材。
- 当前形象先停在这一版，后续放入游戏场景再判断，不继续无限扩展形象方案。

## 已讨论的玩法方向

- 保留三门派各自的组合与大招方向，高费大招需要有足够反馈。
- 提供随机机会，让玩家筛选、重组更适合当前路线的牌组。
- 机制表达避免机械化，猫摊主的荒诞行为与短吐槽需要贴合社畜修仙主题。
- 候选数量、代价、次数与出现频率尚未在本轮明确锁定，不能把提议当成已实现规则。

## 当前实现边界

根据开发分支 README 与项目交接说明，现有浏览器原型已经包含三门派、21种卡牌、奖励保底、动态牌面与存档兼容。本次提交只记录本轮决策，不修改卡牌数值、存档格式或现有流程；猫摊主与随机筛牌事件不因此视为已接入。

本轮未运行代码测试，不沿用交接说明中的历史测试结果作为本轮验证。

## 建议下一步最小任务

先在360×800实际浏览器检查现有原型的操作与布局，再做一个猫摊事件的最小闭环：第一战结束 → 奖励 → 猫摊整理牌组 → 第二战。

建议复用现有事件节点，先验证一次随机筛牌机会；正式实现前明确候选数量、代价与次数。只准备与该事件有关的待机、招揽、成交表情和短台词，避免扩展成新系统。

试玩观察：玩家是否理解筛牌效果、能否更容易组成门派套路、猫的吐槽是否自然、事件是否拖慢原有3–5分钟目标节奏。依据试玩反馈再决定数值与美术深化。
