# 随机奇遇首版 v0.3

2026-10-13，用户确认具体规则并授权实现；将「功法小广告」更名为「野鸡秘籍」，为游戏内原创奇遇，没有视频广告或广告SDK。

## 已确认并实现

- 保留三门派、21种卡、三场战斗、两轮奖励及结局。新局以随机事件替换第一战后固定的删牌/强化节点。
- 两次普通战斗领奖后分别出现0–2个事件，每局总数1–3个，同一类型每局最多一次。猫摊不保证出现，位置不固定。
- 冒险顺序在开局按种子生成并存档。进入事件时按当前种子生成候选牌，随后持久保存；取消选牌、刷新和读档均不重抽。
- 事件均可直接离开；结果立即结算、自动保存。无货币系统，无新增卡牌。
- 最大生命沿用40。10%为4点，20%为8点；恢复不超过40，生命支付后至少剩1点。事件支付不触发战斗受伤被动。

| 类型 | 规则 |
| --- | --- |
| 肥猫摆摊 | 免费完成一次替换。先选一张自己的牌，再看3张不同的本门派或通用候选，选1张换入；可取消重选，候选不变。不保留换出牌的强化，牌组必须留有攻击牌。 |
| 梦里补班 | 恢复4生命；或支付4生命，从3张不同候选中选1张加入牌组；或拒绝。 |
| 打坐被催 | 恢复8生命；或强化1张未强化、可强化的通用牌；或离开。 |
| 野鸡秘籍 | 先展示1张具体候选，支付4生命获得；或离开。 |

候选池为本门派6张牌及3张通用牌，包含大招。这是新事件的规则；此前三门派文档的「大招只在奖励中出现」是v0.2历史边界，已被本首版事件规则扩展。战斗卡牌数值与两轮核心/大招奖励保底不变。

## 实现与兼容

src/events.js负责计划、候选、选择结算及事件存档校验；run.js衔接两轮奖励与下一战；view.js展示选择、费用、牌面效果和禁用原因。

存档键与version=2不变，新局新增adventure字段。没有该字段的旧v2存档继续原固定流程；v1继续迁移为legacy。旧局结局后重开才生成新冒险。损坏存档拒绝加载，不静默清除。

每次替换生成新uid，牌组数量不变；事件获得牌沿用nextUid。选择源牌也保存，读档恢复当前选择。离开或完成事件推进到同一间隔中的下一事件，事件耗尽才进入下一战准备页。
