# 人物素材 v0.3.2

三派以2026-10-16最后认可的暗黑手绘三动作图为依据：年轻社畜、紧凑比例、黑眼圈轻胡茬、完整衣服。原始三动作母图继续保留在对话素材中，运行时版本在本目录随Git提交。不是从其他游戏提取的角色。

- sword.webp：斩仙堂，待机/拔剑/出剑。
- thunder.webp：惊雷府，待机/蓄雷/放雷。
- clone.webp：百身门，待机/结印/指挥分身。
- boss.webp：找回的小吏全身立绘，高黑帽、红印章、卷册；仅在boss敌人上使用，当前静态，不宣称有三动作。

来源索引、尺寸、文件散列、真实Alpha与实际用途见manifest.json。三派先用图像编辑工具移除白底，保留角色造型；运行图以WebP quality88/alphaQuality100编码，不缩放母图尺寸。BOSS已有Alpha，直接编码。生成素材的商用权利仍以所用服务条款为准，无外部素材许可证声明。

动作从同一图集中通过SVG viewBox与连续透明缝隙clipPath非破坏拆分；等高、同一地线，无白色矩形。没有将插画重新画成帧动画。选派使用idle；有效攻击使用attack，技能使用cast，600ms回idle；切换阶段或结束回合取消旧计时器。动作状态不写入存档，不延迟规则结算。

可选build-frames.cjs用于重算裁切配置，需要sharp（本工具环境已有，游戏本身不依赖），在仓库根目录运行。普通运行不需要Node依赖。PNG原母图不由脚本重建。

Cocos工程未接入本轮人物UI。常规小怪保留原占位，不把BOSS重复当作所有怪物。
